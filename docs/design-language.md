# FiyatRadar Design Language v1

## Product feeling
Executive / Warm / Premium / Calm

## Core principle
FiyatRadar uses warm light backgrounds with selective dark premium surfaces and restrained gold emphasis.

The app should feel like a premium market intelligence product, not a discount chaos app.

---

## It should feel like
- premium market intelligence
- structured and calm
- modern and human-centered
- confident but not loud
- polished but not showy
- warm but still elite

## It should never feel like
- cheap discount chaos
- over-glowing luxury parody
- generic marketplace UI
- gaming UI
- cold fintech UI
- noisy campaign brochure design

---

## Visual foundation

### Primary background
Use warm, soft, light surfaces:
- broken white
- soft stone
- warm beige
- creamy neutral tones

These are used for:
- app background
- main page surfaces
- content zones
- list foundations

### Dark premium surfaces
Use dark espresso / bitter brown / deep chocolate tones for:
- hero areas
- premium feature cards
- important insight blocks
- high-value summary panels
- selected strong moments in the UI

Dark surfaces are not for everything.
They are special emphasis surfaces.

### Brown / bronze support tones
Use warm brown / bronze / cinnamon tones for:
- active navigation states
- supporting emphasis
- icon accents
- secondary text emphasis
- premium but grounded visual details

### Gold emphasis
Gold is an emphasis color, not the base color.

Use gold selectively for:
- premium badges
- important pills
- high-value CTA emphasis
- spotlight details
- hero highlights
- trust / prestige / elite moments

Never flood the UI with gold.

### Neutral support tones
Use taupe / muted beige / warm gray-brown for:
- secondary text
- helper text
- divider logic
- subtle borders
- inactive icons
- quiet information

---

## Contrast model
The main contrast structure is:

**light body + dark premium emphasis**

Most screens should follow this principle:
- warm light page foundation
- one strong dark hero or premium emphasis block
- softer cards below
- selective gold emphasis where needed

This contrast model is a core part of FiyatRadar’s identity.

---

## Typography

### Overall style
Typography must be:
- clean
- modern
- highly readable
- premium without being decorative
- confident without being aggressive

### Hierarchy
Use clear hierarchy instead of shrinking everything.

#### Page title
Large, bold, character-rich.
Examples:
- Profil
- Keşfet
- Yardım ve SSS
- Fiyat Ekle

#### Section label
Small uppercase label with letter spacing.
Used for grouping and premium information rhythm.
Examples:
- GÜNÜN NABZI
- HESAP & TERCİHLER
- RADAR ÖZETİ

#### Section title
Strong but smaller than page title.
Examples:
- Bugünün özeti
- En iyi market sıralaması
- Yakın marketler

#### Body text
Comfortable line height.
Never cramped.
Readable at a glance.

### Typography rule
Text hierarchy must create order.
Do not rely on tiny text to fit more content.

---

## Layout philosophy

### General principles
- breathable spacing
- controlled vertical rhythm
- intentional grouping
- no random tight stacking
- clear entry point for the eye

### Screen flow
A typical screen should feel like:
1. strong entry
2. core action or context
3. primary information
4. supporting information
5. secondary discovery

### Layout rule
The user should immediately understand where to start looking.

---

## Density rule
FiyatRadar can contain rich information, but it must never feel messy.

### Rules
- do not show everything at once
- avoid turning screens into card cemeteries
- one dominant area per screen is preferred
- supporting blocks must remain supporting blocks
- remove non-essential noise

Premium feeling comes from controlled density, not maximum density.

---

## Card language

### Premium Dark Card
Use for:
- hero sections
- summary intelligence
- important spotlight blocks
- executive insights
- editor’s choice
- basket advantage moments

Characteristics:
- dark premium surface
- soft glow or light bloom only when needed
- stronger visual weight
- elite but calm tone

### Soft Surface Card
Use for:
- lists
- settings
- categories
- helper modules
- nearby stores
- supporting summaries

Characteristics:
- light surface
- soft shadow
- minimal border logic
- smooth and clean information delivery

### Utility Row Card
Use for:
- settings rows
- FAQ items
- preferences
- quick navigation cells
- structured utility areas

Characteristics:
- simple
- readable
- fast scanning
- icon + text + direction pattern

### Card rule
Do not use too many visually dominant cards on one screen.

---

## Shape language

### Geometry
FiyatRadar uses soft, rounded, premium geometry.

### Radius behavior
Prefer generous radius values.
Use:
- large card rounding
- rounded buttons
- rounded search bars
- pill shapes
- soft containers
- elegant dock / navigation surfaces

### Shape rule
Avoid sharp, aggressive geometry.
The product should feel smooth, premium, and trustworthy.

---

## Button and CTA behavior

### Primary CTA
Use one clear primary action per screen.

Possible patterns:
- dark button on light surface
- warm gold / premium emphasis button on dark surface

### Secondary CTA
Use for supportive actions.
Lower visual intensity.

### Ghost / utility CTA
Use for low-priority interactions.
Should never compete with the primary CTA.

### CTA rule
Not everything should scream for attention.
One main action must clearly lead the screen.

---

## Pills, chips, and badges

### Use cases
- active filters
- status labels
- admin / trusted labels
- level identity
- alerts
- section state
- mini summary indicators

### Characteristics
- soft capsule form
- concise text
- strong contrast
- short and meaningful
- premium but controlled

### Chip rule
Chips are not decoration.
They must communicate useful state or grouping.

---

## Icons
Icons must be:
- modern
- clean
- simple
- systematic
- supportive, not noisy

Use icons for:
- navigation guidance
- category recognition
- interaction clarity
- quick scanning support

Icons are meaning support, not ornament overload.

---

## Glow, shadow, and light

### Glow
Use glow very carefully.

Acceptable use:
- premium dark card corner bloom
- gold-emphasis focus
- selected hero highlight
- prestige badge moments
- high-value CTA support

Not acceptable:
- glow on everything
- neon effects
- constant bright outlines
- cyber UI feeling

### Shadow
Use:
- soft depth
- calm layered elevation
- subtle realism

Avoid:
- harsh drop shadows
- cartoon elevation
- dramatic black shadows

### Light rule
The UI should suggest premium light behavior, not perform it loudly.

---

## Navigation behavior

### Bottom navigation
Should feel like a premium dock:
- soft surface
- stable family identity
- clear active state
- center action can be special but must remain elegant
- no toy-like exaggeration

### Top area
Should feel clean and intentional:
- strong title when needed
- minimal action buttons
- controlled spacing
- no clutter

### Navigation rule
Navigation is not a visual stunt.
It is calm orientation.

---

## Screen role definitions

### Home
Role:
Premium radar center.

Feel:
Insightful, current, premium, but controlled.

Rules:
- one dominant hero
- summary-first thinking
- supporting sections must not overcrowd the page
- avoid turning the home page into an everything page

### Explore
Role:
Search and discovery command center.

Feel:
Systematic, filterable, smart, premium.

Rules:
- search must be visually strong
- filters must feel premium and structured
- product discovery must not feel like generic marketplace clutter

### Add Price
Role:
Fast and trustworthy contribution flow.

Feel:
Controlled, efficient, clear, low-friction.

Rules:
- no messy form chaos
- clear step logic
- confidence and clarity over decoration

### Basket / Comparison
Role:
Savings intelligence.

Feel:
Powerful comparison, clear advantage, executive insight.

Rules:
- show meaningful contrast
- communicate savings clearly
- never feel like a generic shopping cart

### Profile
Role:
Identity, trust, contribution, prestige.

Feel:
Elite but warm, respected but human.

Rules:
- should not feel like gaming UI
- should not feel like banking dashboard
- trust and contribution must feel premium

### Settings / Help / Release Notes
Role:
System confidence and product maturity.

Feel:
Quiet, premium, organized.

Rules:
- even utility screens must feel intentional
- calm structure matters here

---

## Home page density note
The approved visual direction is valid, but the home screen should stay slightly refined in density.

That means:
- preserve the visual family
- preserve the premium hero logic
- reduce unnecessary content stacking when needed
- prioritize breathing room
- favor quality of hierarchy over number of blocks

---

## Forbidden patterns
Do not introduce:
- neon accents
- blue/purple cyber glow
- excessive gradients
- loud e-commerce sale styling
- tiny cramped text
- hard black outlines
- too many competing cards
- random visual styles per screen
- over-decorated glassmorphism
- cheap “luxury” clichés

---

## Final definition
FiyatRadar is a warm premium product with:
- soft light backgrounds
- selective dark premium surfaces
- restrained gold emphasis
- strong typography hierarchy
- soft prestigious geometry
- controlled information density
- calm executive interaction tone

Every screen must feel like it belongs to the same product family.
