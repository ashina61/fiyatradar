# Legacy Exception Allowlist

Bu dosya yalnızca **geçici legacy istisnaları** için kullanılır.

## Format

- PR içinde kural ihlali gerekiyorsa ilgili satıra şu formatla not düşülür:
  - `LEGACY_EXCEPTION: reason=<neden>; owner=<kisi/ekip>; remove_by=YYYY-MM-DD`
- Aynı zamanda bu dosyaya path bazlı kayıt eklenir.
- `remove_by` tarihi geçmiş kayıtla merge yapılmaz.
